# Paradise Nursery Shopping Application

Paradise Nursery is an e-commerce shopping cart web application built with React and Redux Toolkit. It allows users to browse houseplants, add items to a shopping cart, adjust quantities, and calculate total costs dynamically.

## Features
- Dynamic product listing categorized into Air Purifying Plants, Aromatic Plants, and Low Maintenance Plants.
- Redux slice managing shopping cart state (`addItem`, `removeItem`, `updateQuantity`).
- Responsive navbar with dynamic cart item counter.
- Full shopping cart view displaying unit prices, quantities, item subtotals, overall cart total, and checkout prompts.
